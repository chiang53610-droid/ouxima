## Overview

EagleAi Intelligent Fabric Inspection Machine is a one-of-a-kind Taiwanese invention that is entirely
created and manufactured in Taiwan. This fabric inspection machine is equipped with linear cameras that
can effectively recognize defects in elastic and woven textiles. Advanced AI learning algorithms and a
constantly updated defect database shorten training time and improve detection efficiency. A choice of
machine models accommodates various budgets and fabric requirements.

The machine comes with an intuitive operating interface, simplifying the quality control process — colour
differences, labelling issues, edge alignment, or tension detection in elastic fabrics.

**Advantages**
- Suitable for elastic / knit fabric
- Biggest APEC defect database
- Quick ROI through superior productivity
- Permission-based data sharing reduces AI training expenses
- Resource-efficient labor allocation

**User interface**
- Intuitive, easy-to-master UI
- User-specific customizable settings
- Real-time monitoring: remote control; offline operation boosts network security

**Feeding modes**: Flat to flat / Roll to roll / Roll to flat / Flat to roll
**Options**: Labeling device + weighing device + edge-shift layering mechanism

### Reports & integration

- Defect scoring with a **four-point system** report
- Defect mapping / coordinates / classification report
- Defect area analyst report、Colour deviation inspection report、Cutting plan report
- Report formats: CSV, PDF, Excel
- Defect labeling function；fabric recognition module, customizable by fabric type
- System integration with MES / ERP
- Barcode reader (1D / 2D code)

### Detectable defect types

**Station 1** — Yarn knot、Coarse yarn、Foreign fiber、Warp anomaly、Weft anomaly、Broken yarn、Stop mark、
Horizontal line、Snarling yarn、Hole、Press mark、Dye streak、Residual chemical、Color spot、Stain、
Adhesive stain、Oil stain、Tension unevenness、Scratch、Thick and thin places

**Station 2**（須為半透明布料）— Broken weft、Broken warp、Hole、Piece joining、Tension unevenness、
Thick and thin places、Color difference detection

## AI vs. 人工驗布

| 項目 | OSHIMA EagleAi™ | 人工驗布 |
| --- | --- | --- |
| Fabric inspection speed (m/min) | 10–40（依布種） | 18 |
| Downtime (min) | Uninterrupted | 每 20–30 分鐘需休息 |
| Operators required | 1 | 2–5 |
| Measurable criteria | 可量測標準 | 主觀人為判斷 |
| Fabric width measurement | Real-time dynamics | Manual measurement |
| Data collection | 自動 | Manual input |
| Colour variation assessment | 系統判定 | — |
| Interoperability | 可與其他機台整合 | 無法整合 |

> 效率參考：6 分鐘 AI 檢測 ≒ 40 分鐘人工檢測。
