## Overview

EagleAi Intelligent Fabric Inspection Machine is a one-of-a-kind Taiwanese invention that is entirely
created and manufactured in Taiwan. This fabric inspection machine is equipped with linear cameras that
can effectively recognize defects in elastic and woven textiles. Advanced AI learning algorithms and a
constantly updated defect database shorten training time and improve detection efficiency. We provide a
choice of machine models to accommodate various budgets and fabric requirements.

Our EagleAi Fabric Inspection Machine comes with an intuitive operating interface, simplifying the quality
control process. Whether dealing with color differences, labeling issues, edge alignment, or tension
detection in elastic fabrics, our machines can effectively handle them.

**Advantages**
- Suitable for elastic / knit fabric
- Biggest APEC defect database
- Quick ROI through superior productivity
- Permission-based data sharing reduces AI training expenses
- Resource-efficient labor allocation

**User interface**
- Intuitive, easy-to-master UI
- User-specific customizable settings
- Real-time monitoring：remote control；offline operation boosts network security

**進料方式**：Flat to flat / Roll to roll / Roll to flat / Flat to roll
（規格表以 Flat to flat、Roll to roll 兩欄呈現）

## 可偵測缺陷類型

| | v14（2026.08.04） | v9（2024.09.09） |
| --- | --- | --- |
| **Station 1** | Yarn knot、Coarse yarn、Foreign fiber、Warp anomaly、Weft anomaly、Broken yarn、Stop mark、Horizontal line、Snarling yarn、Hole、Press mark、Dye streak、Residual chemical、Color spot、Stain、Adhesive stain、Oil stain、Tension unevenness、Scratch<br>（19 項） | Piece joining、Dirty stain、Hole、Color stain、Dye spot、Knot yarn、Weft yarn abnormal、Chemical spot、Oil stain、Snag<br>（10 項） |
| **Station 2**<br>（須為半透明布料） | Broken weft、Broken warp、Hole、Piece joining、Tension unevenness、Thick and thin places<br>（6 項） | Hole、Broken weft、Broken warp<br>（3 項） |

> v14 的缺陷影像實例（Station 1+2）另外展示 20 張，除上列 Station 1 的 19 項外還包含
> Thick and thin places。
>
> 兩版的命名慣例有調整，以下對應是**依語意判讀，型錄本身沒有明列新舊對照**：
> `Knot yarn` → `Yarn knot`、`Weft yarn abnormal` → `Weft anomaly`、`Chemical spot` → `Residual chemical`、
> `Color stain` → `Color spot`、`Dirty stain` → `Stain`。
> v9 的 `Dye spot`、`Snag` 在 v14 沒有名稱相符的項目（v14 有 `Dye streak`、`Snarling yarn`，
> 但屬於不同缺陷，不宜直接對應）。另外 `Piece joining` 在 v9 屬 Station 1，v14 改列 Station 2。

## AI 驗布 vs 人工驗布

兩版數據相同。

| 項目 | OSHIMA EagleAi™ | 人工驗布 |
| --- | --- | --- |
| Fabric inspection speed (m/min) | 10–40（依布種） | 18 |
| Downtime (min) | Uninterrupted | 每 20–30 分鐘需休息 |
| Operators required | 1 | 2–5 |
| Colour variation assessment | Measurable criteria | Subjective human judgment |
| Fabric width measurement | Real-time dynamics | Manual measurement |
| Data collection methods | Image traceability | Manual input |
| Company reputation | Consistent quality and satisfied customers | Quality disagreements |
| Information unification | Interoperability with other machines | No machine integration |

> 效率參考：6 分鐘 AI 檢測 ≒ 40 分鐘人工檢測。
