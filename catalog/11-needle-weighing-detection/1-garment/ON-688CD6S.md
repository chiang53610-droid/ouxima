## Overview

**Discover an industry pioneer's invention!**

The ON-688CD6S is the most recent needle detecting machine from OSHIMA. Expanded **10-point sensor probes**
improve sensitivity and reliability greatly. The detectors are controlled by a touch screen and have three
sensitivity modes (ΦFe 0.8 mm, 1.0 mm, 1.2 mm), each designed to satisfy certain detecting requirements.
Ideal for use as a single machine or as an addition to existing manufacturing lines.

**Advantages**
- Print function
- Two-hour automatic calibration
- Alarm and conveyor reverse on detection

**User interface**: flat panel touch screen、easy-to-use、multilingual interface
**Best practice**: one-click detection modes、data connectivity、product count（pass / fail / total，時間可調整）
**Investment cost**: easy installation and use、cost-effective maintenance、integrable with other devices
